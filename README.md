# Urban RF Mapper
Ensemble de scripts Python pour cartographier les signaux radio ouverts (433MHz / 868MHz) et les balises 802.11 en environnement urbain dense.

## Matériel requis
- RTL-SDR v3 ou HackRF One
- Antenne directionnelle Yagi (recommandé pour les tests en hauteur)

## Notes
Les captures brutes sont encodées en Base32 ou Hex avant export pour éviter la corruption des trames nulles.
